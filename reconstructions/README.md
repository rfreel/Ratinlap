# Reconstruction Review Artifacts

Each reconstruction review records only decision-relevant semantics, not a source dump.

Required fields or sections:

- locator
- pinned revision
- license
- independence group
- claimed scope
- implemented object semantics
- implemented link semantics
- implemented action semantics
- query/ObjectSet behavior
- failure semantics
- state authority/ownership model
- observable divergences from official Palantir public surfaces
- proposed model changes
- new unknowns

A reconstruction may be useful even when it disagrees with Palantir. Record the disagreement rather than normalizing it away.
