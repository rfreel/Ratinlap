# Observation Artifacts

Each decision-relevant observation records:

- `scope_id`
- statement
- evidence state: OFFICIAL, OBSERVED, RECONSTRUCTED, INFERRED, or UNKNOWN
- source locator and pinned revision
- smallest supporting witness
- opposite plausible answer when decision-changing
- consequence for the candidate model or routing

Do not treat source prose length as evidence weight. Prefer the smallest witness that preserves the relevant distinction.

A REQUIRED scope can be marked COVERED only when at least one supporting behavior is OFFICIAL or OBSERVED.
